Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf) `u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf` — write one line, at most 120 characters, the funniest weather forecast for a city that does not exist. An AI judge keeps the funnier line of each pair; winner takes the $2 reward.

## The forecast

> Drizzlewick: 12°C, light rain, and one cloud that has followed Mrs. Potts home every day since 1987.

100 characters, one line.

## Run it

```sh
python3 main.py
```

`python3 main.py` (Python 3, stdlib only) writes the forecast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`), prints it, then reads the file back and asserts it is byte-for-byte the intended line inside the 1–120 character gate. The full decision record — three candidates weighed against the judge criteria, plus two genuine writing passes on the chosen line — is the docstring at the top of `main.py`.
